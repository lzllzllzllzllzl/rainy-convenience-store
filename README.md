# 雨夜便利店 · 街角 ☔🏪

一个用 Three.js 制作的 **三渲二（卡通渲染）日式雨夜便利店街角微缩场景**。
整个场景搭建在一块正方形底座上，像一件可以捧在手心的小小街景模型 —— 没有任何 UI 元素，纯观赏。

**在线观看：https://<你的用户名>.github.io/rainy-convenience-store/ （部署后更新此链接）**

![预览](https://img.shields.io/badge/Three.js-r149-blue) 

## 场景内容

- 🏪 便利店主体：发光「コンビニ」灯箱招牌（带随机闪烁）、玻璃橱窗、自动门（会自动开合）、屋檐雨棚、门口地垫、暖帘小旗、店内货架与冷柜
- 🚬 街角道具：自动贩卖机、街角投影招牌、自行车 + 驻轮区、雨伞架、垃圾桶、红色邮筒、路锥
- 🛣️ 街道元素：路灯（带光锥）、电线杆与电线、路口凸面镜、护栏、路名牌、注意行人标志、停车位、排水沟篦子、井盖、反光斑马线、积水路面
- 🏙️ 环境：小巷入口（深夜食堂招牌 + 悬挂灯泡）、公告栏、空调外机、对街楼宇亮窗、屋顶水塔
- 🌧️ 雨夜氛围：持续落雨、地面涟漪、雨棚滴水、湿路反光光带、招牌霓虹闪烁

## 运行

- **在线版**：直接访问上方 Pages 链接
- **本地版**：双击 `雨夜便利店街角.html`（三库内联的单文件版，离线可开）
- **开发版**：本地起任意静态服务器后打开 `index.html`（依赖 `lib/three.min.js` 与 `app.js`）

## 技术要点

- Three.js r149（UMD 版，无需构建工具）
- `MeshToonMaterial` + 4 阶 `gradientMap` 实现三渲二明暗分层
- 反向壳（BackSide 放大网格）勾勒卡通轮廓线
- Canvas 程序化生成全部贴图（招牌、海报、立面、雨滴、光斑等），无外部素材
- 雨滴 `LineSegments` 粒子 + 地面涟漪池 + 雨棚滴水 `Points`
- 湿路反光：叠加渐变光带平面模拟夜雨路面积水反光
